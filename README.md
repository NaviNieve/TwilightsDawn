# Twilights Dawn - Profile Creator/Editor Suite

Designed to decrypt, validate, and serialize offline profile save matrices for a custom Warcraft III named 'Twilight's Eve Evo RPG'. Built natively on Python and Tkinter, this architecture integrates automated error-boundary enforcement loops, fluid-width layout alignment modules, and a thread-isolated asynchronous network update engine.

## 🛠️ System Pre-requisites & Dependencies

Ensure your execution has Python 3.10+ registered alongside the specialized Tkinter drag-and-drop extensions layer:

```bash
pip install tkinterdnd2 pyinstaller
```

### Compilation Pipeline
Download from Releases or compile it yourself into a standalone, single-click Windows binary executable with a suppressed console footprint, execute the following PyInstaller routine:

```bash
pyinstaller --noconfirm --onedir --windowed --add-data "modules;modules/" --add-data "ui;ui/" --add-data "dumper;dumper/" main.py
```
